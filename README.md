# Late Summer Screening Room

《夏末放映室》（Late Summer Screening Room）是一款基于 SpriteKit 和 Objective-C 开发的多结局互动视觉小说。

## 项目内容

- `GameTemplate/`：iOS 游戏源码、剧情数据、运行资源和 Xcode 工程。
- `resource/AppStoreScreenshots/`：App Store 上架截图，包含 iPhone 和 iPad 五图。
- `app_store_metadata.md`：App 名称、副标题、介绍文字、关键词、版权信息和上架备注。
- `index.html`、`privacy.html`：Vercel 隐私政策站点源码。

## 构建

1. 安装 Xcode 及 CocoaPods。
2. 进入 `GameTemplate` 目录并执行 `pod install`。
3. 使用 `GameTemplate.xcworkspace` 打开工程。
4. 选择 `GameTemplate` scheme 构建或运行。

项目最低支持 iOS 13.0。依赖版本记录在 `GameTemplate/Podfile.lock` 中。
